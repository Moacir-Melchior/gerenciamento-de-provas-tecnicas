# PDFs das provas

Os PDFs ficam organizados por colaborador e tipo de prova:

    pdfs/<colaborador>/<tipo-de-prova>/<aaaa-mm-dd>.pdf

Exemplo: `pdfs/joao-da-silva/auxiliar-mecanico-2/2026-11-17.pdf`

Esta pasta é preenchida automaticamente pelo botão **Publicar no GitHub**
(ou manualmente, seguindo o caminho acima).
